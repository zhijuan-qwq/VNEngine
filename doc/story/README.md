# 剧本全文 · 记法说明

> 本目录为《星星落进我家冰箱》确认用剧本全文，按章节分文件。落地阶段将按本文本机械转换为单一 `.vns` 脚本。
>
> 文风基准（用户指定参考）：第一人称「我」叙述 +「我（心声）」内心独白承担旁白与观察；短句、留白、动作化立绘指示；场景编号标题；【SE】音效标注。

## 记法

- 场景标题：`场景 N｜地点｜时间`。
- `【BG xxx】` 切换背景（资源 ID 见设计案 §8.1）；`【BGM 氛围描述｜曲目ID 循环/fadein】` `【BGM 停】` 音乐控制。
- `【SE 拟音】`：音效氛围标注。**引擎无 SE 资源，落地时跳过不转换**（仅作阅读节奏参考）。
- `【特效 rain/shake/flash/snow】` `【特效 停】`：画面特效指示。
- `【立绘】星弥（魔女装|便服・姿态・表情）`：姿态 f1=站立 / f2=持杖 / s1=侧身合十；表情变化用 `→` 连写，如 `【立绘】星弥（惊呆 → 闭眼）`；`【立绘 隐藏】` 退场。
- 台词格式 `说话人（表情）：台词`，表情仅在变化时标注；`+红晕` `+泪` 为脸颊差分。
- **说话人约定**：男主说话人显示为「我」，内心独白为「我（心声）」（落地时心声以斜体呈现）；女主「星弥」；路人按出场名（小孩、老板、？？？等）。男主本名「林寻」只出现在对白中被他人称呼，不作为说话人名。
- `【选项 N-M】` → `A/B/C…` 选项，括注好感度增减与 flag；`【分支 …】` 为条件闸门。
- `[pause=400]` 等富文本标记直接内嵌在台词中，落地原样保留。
