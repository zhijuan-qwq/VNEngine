# 《星星落进我家冰箱》剧情设计案

> 状态：**v0.2 已确认关键设定**（男主：林寻 / 标题：《星星落进我家冰箱》 / 篇幅：标准版 6 章约 650 句 / 结局：4 结局）— 剧本全文见 `doc/story/`，确认后进入落地阶段（资源接入 + `.vns` 转换 + 串联调试）
>
> 一句话简介：一个加班的普通社畜，与一位吃了他的蛋糕就赖着不走的百年魔女，在为期一年多的同居日常里，学会直面"会结束的时间"的故事。

---

## 1. 概念与主题

- **类型**：现代日常系恋爱视觉小说，单女主、单线主轴 + 多结局分支
- **主题**：_正因为会结束，每一天才算数。_
  - 女主拥有近乎永恒的寿命，却停在了"14 岁"的样子；她害怕的不是死亡，而是"再一次成为被留下的人"。
  - 男主作为普通人给出的答案不是魔法，而是一个个"一年之约"。
- **基调**：温暖治愈的日常喜剧为底色，中段渗入淡淡的忧伤，结局回落于温柔。
- **体量（提案）**：6 章，约 600~~650 句对话，游玩时长约 50~~70 分钟；4 个结局。

## 2. 世界观使用规则（红线）

依 `~/桌面/res/world_description.md`：**里世界绝不作为主线叙述场景，只提供钩子与剧情推力，全篇所有场景均在表世界。**

里世界在本作中的全部露出（共 5 处，均为对话/道具层面的点到即止）：

1. 星弥的出身（序章起的所有暗示）；
2. "契约"规则——里世界的人可与人签订契约，赋予对方与自己相同的近乎永恒的寿命（终章抉择的支点）；
3. 大魔女的一封信（第四章转折的推力：星巡之夜，归途之门将开一次）；
4. "里世界的星星会唱歌"（第三章夜公园的一句台词）；
5. 终章的"门"与离别结局里"每年一朵烟花"的信。

## 3. 角色

### 星弥（xingmi）— 女主，可操作立绘

沿用 `ch_description.md` 全部设定：100+ 岁、3 月 14 日生日、145cm、魔女；活泼冒失、好奇心旺盛、敏感细腻。

本作补充（与原设定兼容的演绎）：

- 因一场魔法事故停止成长，这是她"笑容之下忧伤"的来源：她曾对一位收留她的老人提出缔结契约，被老人以"正因为会结束，每一天才算数"拒绝，老人随后寿终正寝。她因此封住真心，独自旅行——直到闯进男主的家。
- 服装语义：**魔女装（clothes1）= 魔女身份/家中/重要场合**；**便服（clothes2）= 融入表世界的日常**。换装本身是剧情演出手段（第四章末她换回魔女装 = 准备离家的信号）。

### 男主 — 林寻（玩家视角，无立绘）

- 普通公司职员，独居公寓，会做饭（甜点是他唯一的爱好）。名字取"寻"之意：**在浑浑噩噩的日子里，找寻自己内心真正所求**——这是他的角色弧线：开工时他的生活只有"上班→便利店布丁→睡觉"，是星弥的到来让"想要什么"这件事重新变得具体。
- 说话人约定（参考文风）：男主对白显示为**「我」**，内心独白为**「我（心声）」**（心声落地时以斜体呈现，承担全部场景描写、观察与吐槽；不设独立"旁白"说话人）。他的本名「林寻」只出现在对白中被星弥等称呼，不作为说话人名。
- 与主题的呼应：星弥拥有无限的时间却不敢"想要"（怕失去）；林寻拥有有限的时间却从未"想要"过（麻木）。两人互为答案——真结局里他找到的东西"不在远方，在冰箱里少了半块蛋糕的地方"。

## 4. 总体结构与时间轴

```
初夏暴雨夜        夏              夏末~秋         冬~春            春               盛夏流星雨
序章:闯入    →  第一章:同居   →  第二章:雨天  →  第三章:游乐园  →  第四章:大魔女  →  终章:星巡之夜
 (6月雨夜)      规则(日常)      蛋糕(梅雨)      约会(尾声入秋)    的信(初春)       (次年8月)
```

- 情绪曲线：喜剧 → 温暖 → 隐忧 → 高光 → 转折/低谷 → 抉择与释放。
- 全部剧情约 14 个月，跨度用背景的昼夜与季节变体 + BGM 曲名（春之日/西瓜/雨粒…）自然交代，不做冗长过场。

## 6. 分支与结局设计

### 6.1 好感度系统

- 变量 `$affection`，初始 0；全程 9 个选项（§5 各表），温柔项 +10、中性项 +5、损人项 +5、伤害项 -5。
- 理论上限 85；**真结局门槛 50**（≈七成温柔即可达成，故意全程冷漠才会进入 Normal End——短篇以"让玩家看到真结局"为先）。
- 辅助 flag：`heard_age`（第二章追问）、`met_xingmi`——只影响第四章对话细节，不影响结局。
- 好感度数值不显示在画面上（避免破坏叙事沉浸）。

## 7. 文风与台词样例（序章节选）

> 文风基准（用户指定参考）：第一人称「我」+「我（心声）」内心独白承担旁白与观察；短句、留白；动作化立绘指示；场景编号标题；【SE】音效标注（无资源，落地跳过）。完整记法见 `doc/story/README.md`。

```
场景 4｜林寻的公寓·客厅｜同夜

【BG living_room_3】【BGM 停】【特效 停】
我（心声）：开门。玄关的灯应声亮起。
我（心声）：然后，我看见了。
我（心声）：餐桌歪着。椅子倒着。冰箱门大敞，像一张惊愕的嘴。
我（心声）：我放在冰箱顶上的草莓蛋糕，盒子空了，躺在客厅正中央。
我（心声）：奶油在地板上拖出一条白色的痕迹，一路延伸到沙发。
我（心声）：痕迹的尽头，睡着一个戴巨大尖顶帽的小小身影。
```

- 「我（心声）」是文风核心：场景描写、观察、诗意点题全部由它承担，不设独立"旁白"；心声落地时以斜体呈现。
- 星弥台词保留"冒失 → 强撑 → 偶尔露真心"的节奏；短句与 `[pause=N]` 制造喜剧停顿与情绪留白。

## 9. 落地备注（引擎约束 → 剧本写法红线）

1. **单一 `.vns` 脚本**（`public/script/game.vns`）：跨脚本标签跳转不受支持，单文件同时保证存档（scriptPC）在全篇任何位置可读档。
2. **`@if` 块内禁止阻塞命令**（`@say`/`@choice`/`@wait`/`@pause`）：引擎存档机制在 `@if` 块内读档会报错（script-dsl.md §5.6）。全部 `@if` 块只放 `@jump`/`@set`/`@flag`/`@add` 等瞬时命令，等待点一律位于顶层流程。**不使用 `@call`/`@return`**（同理）。
3. **说话人语法**：中文说话人只能用 `@say "星弥" "…"` 形式（内联糖 `星弥 "…"` 仅支持 ASCII 标识符）。说话人映射：「我」→ `@say "我"`，「我（心声）」→ `@say "我（心声）"` + 正文包 `[i]…[/i]` 斜体，星弥 → `@say "星弥"`（序章登场前为 `？？？`），路人按剧本标注名。
4. **无 SE / 环境音 / 语音资源**：剧本中的【SE 拟音】标注**落地时跳过不转换**；不使用 `@playSe` / `@playAmbient` / `@playVoice` / `voice=`；氛围靠 BGM 选择与 `[pause]` 节奏。
5. 特效仅用已实现的 `@rain` / `@snow`（冬季过场）/ `@flash` / `@shake` / `@stopEffect`；转场用 `fade`/`slideL`/`slideR`/`zoom`。
6. 富文本仅用 `[pause=N]`、`[i]`（心声斜体）、少量 `[color]`；`{$var}` 不用于正文。
7. 立绘资源经 manifest 以 `xingmi_*` 命名注册（480 项，脚本生成 manifest，不手写）；背景 41 项、BGM 27 项。
8. 暂不做标题画面：`main.ts` 配置 assets + scripts 后直接进剧本（如需要标题画面，属落地阶段增量，另行确认）。
