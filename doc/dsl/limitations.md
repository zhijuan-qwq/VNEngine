# 已知限制与后续计划

本目录的文档描述的是**当前代码的实际行为**。这份文件集中记录两类内容：容易踩坑的限制，以及已经确认方向、但尚未实现的改动。

只写剧本时不必先读它；遇到「文档说可以，但运行结果不对」的情况，再回来查。

## 1. 对话与语音

- `@say` 的 `adv` / `nvl` 只记录在 `script:say` 事件里，**不会改变对话框外观**。`@say` 不写模式时默认 `adv`；`@choice` 不写 `mode=` 时同样默认 `adv`。
- 对话行的 `voice=资源id` 只记录在事件里，**不会播放语音**。要真的播放，用 `@playVoice`。
- `speed=` 会覆盖默认打字速度，这一项是生效的。

## 2. 参数与校验

- 每条指令都会按声明的参数表校验：未知的键值参数、类型不对的值、多余的位置参数、需要时长的位置写成裸数字，都会在运行到该指令时通过 `script:error` 报错。
- 数字型键值必须写成不带引号的数字。`volume="0.5"` 现在是类型错误，不会再被静默忽略。
- `@say` 和 `@choice` 走专用语法：`@say` 拼错键名或多写位置参数、内联对话多写参数、`@choice` 拼错 `mode=`，都在解析阶段报错。
- 不含任何选项的 `@choice` 在解析阶段报错。
- 位置参数和键值参数同时给出时，位置参数优先；只有 `@flash` 同时写位置时长和 `duration=` 会报冲突。
- 音量、强度、密度等数值仍不做范围校验，超出常用范围不会报错。
- 位置参数的绑定顺序是固定的几处：
  - `@hide` 永远把第一个位置参数当作角色 id。`@hide fade` 会尝试隐藏名为 `fade` 的角色，而不是「带淡出隐藏全部」。
  - `@playBgm` / `@playAmbient` 第一个位置参数永远是资源 id，`loop` / `once` 写在它后面。
  - `@set` 等变量指令第一个参数必须是 `$变量`，表达式的数量由语法强制。

## 3. 时长

- 时长必须带单位：`500ms`、`1.5s`。裸数字（`500`）会被当作参数类型错误。
- `@wait` 必须写合法时长，不写会报错。
- 负时长会在参数校验阶段报错。

## 4. 选项块

- `@choice` 和 `@endchoice` 之间可以写空行和整行注释，行尾注释也可以。
- 一个选项都没有的 `@choice` 会在解析阶段报错。
- 选项条件为假时，选项仍会显示，只是变灰、点不了。**如果所有选项的条件都为假，玩家会卡在选择界面**，引擎目前没有保底处理。

## 5. 名字与元数据

- 名字可以使用 ASCII 字母、数字、下划线、连字符和汉字，并且不能用数字或连字符开头。标签名、变量名、旗标名和表达式里的普通词共用这套规则。
- 资源 ID、`@flag` 的参数加引号后可以是任意字符串（包括空格）。
- 名字允许连字符，所以 `$hp-1` 是**一个名为 `hp-1` 的变量**，不是 `$hp` 减 1。减法要写成 `$hp - 1`。
- 元数据键必须完整匹配：`@titlefoo bar` 会被当成名为 `titlefoo` 的指令，加载时报「不认识的指令」。
- 元数据值只有「整段就是一个双引号字符串」时才会去掉引号。`@title "A" x` 的值是 `"A" x`，引号会保留。裸文本和引号混写并不等价。
- 元数据重复、顺序不对，以及标签重复，都在解析阶段报错；错误对象带 `phase: "parse"` 和 `line`。

## 6. 内联对话的说话者

- 内联写法 `角色名 "台词"` 的说话者可以是普通名字，也可以是带引号的字符串：`Hero`、`narrator_2`、`"???"`、`"旁白"`、空名 `""` 都合法。
- `@say` 的说话者同样支持普通名字或带引号的字符串：`@say Hero "你好"`、`@say "旁白" "……"` 都可以。

## 7. 富文本

- 粗体、斜体、颜色、字号都会应用到实际渲染。
- `[size=N]`、`[speed=N]`、`[pause=N]` 的值不合法（空值、非数字、超出范围）时会报错，不再是静默丢弃。
- `[color=...]` 只接受 `#rgb`、`#rrggbb`、`#rrggbbaa`，其他格式会报错。
- 闭标签必须和最近打开的标签同名；不匹配的闭标签会原样显示。
- `[ruby]` / `[shake]` 不再是特殊标签，会连同内容一起原样显示。
- 不认识的标签、没闭合的 `[` 会原样显示。没有转义语法。
- 变量不存在时，`{$名字}` 输出空串。

## 8. 画面特效与转场

- 转场名只认 `fade`、`slide`、`slideL`、`slideR`、`zoom`、`none`。脚本里写其他名字会作为参数错误报错；渲染层收到未知名字时仍按直切处理。
- 缓动名只认 `linear`、`ease`、`easeIn`、`easeOut`、`easeInOut`。脚本里写其他名字会报错；渲染层收到未知名字时回退 `linear`。
- `@flash` 同时写位置时长和 `duration=` 会报错。
- `@playBgm` / `@playAmbient` 都支持 `loop`、`once` 和 `loop=N`。

## 9. 变量、除零与存档

- 除以 0 或对 0 取模不会报错，结果是 `Infinity`、`-Infinity` 或 `NaN`。
- 存档使用 `JSON.stringify`，所以这些值会被写成 `null`；值为 `undefined` 的变量会直接从存档里消失。
- 用未定义变量参与算术会得到 `NaN`；直接交给 `@add` / `@sub` 这类指令会报 `Expected a number, got undefined` 的运行时错误。
- 右侧引用一个不存在的变量时，`@set $x $missing_var` 会把 `x` 设为 `undefined`。之后读出来在条件里为假、在文本插值里为空串，存档时该键会消失。

## 10. 流程结构

- `@if` 是否闭合、`@endif` 是否多余，都是**运行时**才检查，不是加载时：
  - 没有配对的 `@endif`：执行到 `@if` 时报 `Unclosed @if block`；
  - 多余的 `@endif`、`@elseif`、`@else`：执行到该行时报错。
- `@if` / `@elseif` 漏写条件会在解析阶段报错，不再退回通用指令解析。
- `@else` 写在 `@elseif` 之前不会报错。第一个成立的分支会执行，后面的分支全部跳过。
- `@return` 没有对应的 `@call` 时，运行到它才报 `Call stack is empty.`。
- `@jump` / `@call` 的标签不存在或没写标签名，也是运行时错误。
- 无参流程指令（`@else`、`@endif`、`@end`、`@return`）多写参数会在运行时通过 `script:error` 报错。
