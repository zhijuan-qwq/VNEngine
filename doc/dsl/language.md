# 语言规则

这份文档讲所有指令共用的规则。只想知道某条指令怎么写的，查 [reference.md](reference.md)；第一次写剧本，从 [guide.md](guide.md) 开始；遇到与预期不符的行为，查 [limitations.md](limitations.md)。

## 1. 一行一条指令

正常情况下，一行写一条指令，执行顺序就是从上到下。

唯一的例外是选项块：`@choice` 和 `@endchoice` 之间要写多行选项，它本身就是一个多行结构。

空行会被忽略。缩进没有任何语法含义，只是让剧本更好读。整份脚本可以是空的，不会报错。

## 2. 注释

用 `//` 写单行注释。它有两种位置：

```vns
// 整行注释
@bg classroom // 行尾注释
@set $x 1 // 赋值
```

不支持多行注释。

裸文本形式的元数据值会在 `//` 处截断，所以值本身含 `//` 时要用双引号：

```vns
@title 第一章 // 这不是标题的一部分
```

```vns
@title "A // B"
```

选项块内部可以写空行和整行注释，行尾注释也可以：

```vns
@choice
  // 任意整行注释
  -> "回应她": respond // 这里也可以写
@endchoice
```

## 3. 名字

标签名、变量名、旗标名（`?名字`）以及表达式里的普通词都用同一套名字规则：

- 可以使用 ASCII 字母、数字、下划线和连字符，也可以使用汉字；
- 以字母、下划线或汉字开头，不能以数字或连字符开头；
- 区分大小写。

例如 `ch_hero`、`chapter2_start`、`auto_mode`、`farLeft`、`开始`、`好感` 都是合法的名字。

资源 ID 和旗标指令（`@flag` / `@unflag` / `@toggle`）的参数是普通值，可以写成带引号的字符串，此时不受名字规则限制，空格等字符都可以：`@bg "class room"`、`@flag "中文 旗标"`。不带引号时必须符合上面的名字规则（汉字可以，空格不行）。

名字里允许连字符，这有一个容易踩的坑：`$hp-1` 是**一个名为 `hp-1` 的变量**，不是 `$hp` 减 1。减法必须写成 `$hp - 1`，运算符两边加空格。

## 4. 字面量

| 类型   | 写法                    | 例子                         |
| ------ | ----------------------- | ---------------------------- |
| 字符串 | 双引号包围              | `"你好"`、`"第一行\n第二行"` |
| 数字   | 十进制，可带负号和小数  | `42`、`-7`、`3.14`、`-0.5`   |
| 布尔值 | `true` / `false`        | —                            |
| 时长   | 数字加 `ms` 或 `s` 单位 | `500ms`、`2s`、`1.5s`        |
| 普通词 | 不带引号的名字          | `classroom`、`center`        |
| 变量   | `$` 加名字              | `$affection`                 |
| 旗标   | `?` 加名字              | `?met_hero`                  |

几点说明：

- 字符串只支持双引号，转义只认 `\n`、`\t`、`\\`、`\"` 四种。
- 数字不写科学计数法，`1e3` 不是数字。
- 时长必须带单位：`500ms`、`1.5s`。裸数字不是合法时长，`@wait 500` 会在运行时报错，应写成 `@wait 500ms`。
- 普通词会原样变成字符串。`@bg classroom` 里的 `classroom` 就是一个字符串。
- 普通词只能由名字允许的字符组成，所以 `#ffffff`、`#ff0000` 这类值必须加引号：`color="#ffffff"`。直接写 `color=#ffffff` 会解析失败。

## 5. 指令参数

指令后面可以跟两类参数：

- **位置参数**：不带名字的值，按值的类型匹配到指令声明的槽位。
- **键值参数**：写成 `名字=值`，例如 `sprite=smile`、`volume=0.5`。

键值参数的右值可以带引号，引号里允许空格：

```vns
@say Hero "你好" speed=30
@bg classroom fade 1s
@bg "class room" fade 1s
@show ch_heroine right transition=fade duration=500ms
```

`"class room"` 是一个带空格的字符串值：引号会被去掉，空格保留。

### 位置参数怎么匹配

每条指令都声明自己接受哪些位置参数和键值参数。位置参数按**值的类型**匹配到槽位，而不是简单按下标填空：

- 合法位置名（`left`、`center` 等）填位置槽；
- 合法转场名（`fade`、`slideL` 等）填转场槽；
- 合法缓动名（`linear`、`easeOut` 等）填缓动槽；
- 带单位的时长填时长槽；
- 其余字符串按指令声明的顺序填资源 id 等普通字符串槽。

因此可以省略中间的可选槽位。例如：

```vns
@show ch_hero slideL 500ms
@move ch_hero 500ms easeOut
@bg classroom 1.5s
```

`@show` 省略位置时，`slideL` 会被识别成转场，不再被吞掉。

有几处绑定是固定的：

- `@hide` 的第 1 个位置参数永远是角色 id，所以 `@hide fade` 是「隐藏 id 为 `fade` 的角色」；隐藏全部并带转场要写 `@hide all fade`。
- `@playBgm` / `@playAmbient` 的第 1 个位置参数永远是资源 id，`loop` / `once` 写在它后面。
- `@set` 等变量指令的第 1 个参数必须写成 `$变量`，后面跟规定数量的表达式；`@random` 依次是变量、下界、上界。

### 参数会被自动校验

以下情况会报错（运行到该指令时通过 `script:error` 报告）：

- 未知的键值参数，或类型不匹配的值，例如 `volume="0.5"`、`@move` 里未知的位置/缓动名；
- 多余的位置参数；
- 需要时长的位置写成裸数字，例如 `@wait 500`、`@shake 500`；
- `@wait` 不写时长；
- `@flash` 同时写位置时长和 `duration=`；
- `@set` / `@random` 等变量指令多写或少写表达式（这一类在解析阶段报错）。

位置参数和键值参数同时给出时，位置参数优先；只有 `@flash` 的两种时长写法会报冲突。`@bg`、`@show`、`@hide`、`@move`、`@sprite` 都接受 `transition=` / `duration=` / `easing=` 这类等价写法。

`@say` 和 `@choice` 的参数形状由专用语法决定：`@say` 拼错键名或多写位置参数会直接解析失败；内联对话多写参数也会解析失败。同一个键值参数写两次同样在解析阶段报错。

值本身是数字、但写成了字符串（例如 `volume="0.5"`）时，现在会按类型错误报告，而不是悄悄忽略。

## 6. 元数据

元数据只有三个键：

| 键         | 说明     |
| ---------- | -------- |
| `@title`   | 剧本标题 |
| `@author`  | 作者     |
| `@version` | 版本号   |

元数据必须排在所有指令和标签之前，每个键只能出现一次。重复出现、顺序不对都会在解析阶段报错。元数据之前可以有注释和空行，只要还没出现真正的指令或标签。

值的写法有两种，但**只在简单情况下等价**：

- 整段值是一个双引号字符串时，引号会被去掉：`@title "第一章"` 的值是 `第一章`；
- 否则整行到 `//` 之前都算裸文本，去掉首尾空白，**引号原样保留**：`@title 第一章` 的值是 `第一章`，`@title "第一章" 外传` 的值是 `"第一章" 外传`。

所以 `@title "A"` 和 `@title A` 等价；一旦引号和普通文字混写，就不再等价。

元数据键名必须完整匹配：`@titlefoo bar` 不是元数据，会被当成名为 `titlefoo` 的指令，加载脚本时报「不认识的指令」。

## 7. 脚本结构

一份脚本由下面这些行组成：

- 元数据行，例如 `@title ...`；
- 标签行，例如 `@label start`；
- 对话行：内联式 `Hero "你好"` 或 `@say Hero "你好"`；
- 普通指令行，例如 `@bg classroom`；
- 选项块 `@choice ... @endchoice`；
- 空行和注释行。

标签用 `@label 名字` 声明，是跳转和调用的落脚点。标签名不能重复，重复会在解析阶段报错。标签可以出现在使用它的 `@jump` / `@call` 之前或之后。

内联对话的说话者可以是普通名字，也可以是带引号的字符串，所以中文、`"???"` 和空名都可以直接写：

```vns
Hero "你好。"
旁白 "……"
"???" "......"
"" "没有名字的台词。"
```

`@say` 的说话者也同样支持普通名字或带引号的字符串：`@say Hero "你好。"`、`@say "旁白" "……"` 都合法。

## 8. 流程

### 跳转、调用与返回

```vns
@label start
@jump chapter2_start

@call explore_scene
@return
```

- `@jump 标签` 无条件跳到标签处，不记录返回位置。
- `@call 标签` 调用一段子流程，并记下返回位置。
- `@return` 回到最近一次 `@call` 的下一条指令。

在 `@if` 块里 `@jump` 到块外是允许的，不需要先补 `@endif`。跳转不会影响 `@call` 的返回位置。

下面这些情况会在**运行时**报错，而不是加载时：

- 标签不存在，或者 `@jump` / `@call` 没写标签名；
- `@return` 时调用栈是空的（没有对应的 `@call`）。

### 条件分支

```text
@if 条件
  ...
@elseif 另一个条件
  ...
@else
  ...
@endif
```

`@if` 必须带条件；`@elseif` 可以有多个；`@else` 和 `@endif` 各写一个。条件为真时，执行到下一个分支标记为止。

`@if` / `@elseif` 漏写条件会在解析阶段报错，不会被静默当作「假」。

分支结构是嵌套的，`@if` 里可以再写 `@if`。结构错误在运行到相关行时才暴露：

- `@if` 没有配对的 `@endif`：执行到 `@if` 时报 `Unclosed @if block`；
- 多余的 `@endif`、`@elseif`、`@else`：执行到该行时报错；
- `@else` 写在 `@elseif` 之前**不会报错**：第一个成立的分支先执行，后面的全部跳过。

## 9. 选项块

```vns
@choice
  -> "回应她": respond
  -> "无视她": ignore
  -> "恶作剧": prank if $confidence >= 50
@endchoice
```

- 选项行以 `->` 开头，`->` 后面至少要有一个空格。
- 缩进可有可无，只影响好看。
- 冒号后面是选中后跳转的标签名。
- `if` 后面是可选的显示条件。
- 行尾和整行都可以写 `//` 注释，块内也可以有空行。

条件不成立的选项仍然显示，只是变灰、点不了。没写 `if` 的选项始终可点。玩家点中后，脚本跳到对应标签。

一个选项都没有的 `@choice` 会在解析阶段报错。所有选项的条件都为假时，玩家会卡在选择界面，详见 [limitations.md](limitations.md)。

`@choice` 可以写 `mode=adv` 或 `mode=nvl`，不写时默认 `adv`。这个值会记录在事件里，但**目前不会改变画面**。

## 10. 表达式

表达式可以用在三个地方：

- `@if` / `@elseif` 的条件；
- `@set`、`@add`、`@sub`、`@mul`、`@div`、`@mod`、`@random` 的右值；
- 选项行的 `if` 条件。

示例：

```vns
@set $total $base + $bonus
@sub $hp 1
@set $hp $hp - 1
@random $dice 1 6
@if $affection >= 80 and ?met_hero
```

注意 `@sub $hp 1` 是在原值上减 1；`@add $hp $hp - 1` 会变成「原值加上原值减一」，通常不是想要的结果。

### 运算符与优先级

从高到低：

| 优先级 | 运算符                      |
| ------ | --------------------------- |
| 1      | `!` `-`（一元）             |
| 2      | `*` `/` `%`                 |
| 3      | `+` `-`（二元）             |
| 4      | `>` `>=` `<` `<=` `==` `!=` |
| 5      | `and`                       |
| 6      | `or`                        |

可以用括号改变顺序。比较运算不能连写，`1 < $x < 3` 不合法，要写成 `1 < $x and $x < 3`。

### 书写要求

- 二元运算符两侧必须有空格：`1 + 2` 合法，`1+2` 不合法。
- 一元运算符可以紧贴操作数，也可以连续写：`-$x`、`!!$flag` 都合法。

### 求值规则

- `and` / `or` 会短路：`and` 左侧为假时直接返回 `false`，`or` 左侧为真时直接返回 `true`，右侧不再求值。两者始终返回布尔值。
- `==` / `!=` 同时比较类型和值，`1` 和 `"1"` 不相等。
- 大小比较和加减乘除按 JavaScript 的规则计算；`+` 也可以拼接字符串。
- 真假的判断：`false`、`0`、`NaN`、空字符串、未定义都算假，其余算真。
- 除以 0 不会报错，会得到 `Infinity`、`-Infinity` 或 `NaN`。这些值存档后会变成 `null`。
- 没定义的变量：在条件里当作假，在文本插值里输出空串，参与算术时得到 `NaN`。如果直接把它交给 `@add` / `@sub` 这类需要数字的指令，会报 `Expected a number, got undefined`。
- 右侧引用一个不存在的变量时，`@set $x $missing_var` 会把 `x` 设为未定义值；之后存档时这个键会消失。
- `?名字` 检查旗标是否存在。

## 11. 内联富文本

台词里可以加少量格式标签。标签只影响显示，不影响脚本逻辑。

| 标签                         | 作用             | 例子                            |
| ---------------------------- | ---------------- | ------------------------------- |
| `[b]...[/b]`                 | 加粗             | `"[b]重要[/b]"`                 |
| `[i]...[/i]`                 | 斜体             | `"[i]内心独白[/i]"`             |
| `[color=#rrggbb]...[/color]` | 文字颜色         | `"[color=#ff0000]红字[/color]"` |
| `[size=N]...[/size]`         | 字号             | `"[size=32]标题[/size]"`        |
| `[speed=N]`                  | 改变后续打字速度 | `"[speed=30]慢一点"`            |
| `[pause=N]`                  | 停顿 N 毫秒      | `"然后...[pause=1000]他走了。"` |
| `{$名字}`                    | 插入变量值       | `"好感度：{$affection}"`        |

所有样式标签都会实际影响显示：`[b]` / `[i]` 加粗或斜体，`[color=...]` 改颜色，`[size=N]` 改字号；`[speed=N]` / `[pause=N]` 控制打字速度和停顿，`{$名字}` 替换变量。

`[speed=N]` 和 `[pause=N]` 是一次性标记，没有配对的结束标签。写成 `[/speed]` 不会被识别，会原样显示。

其余规则：

- 标签可以嵌套，例如 `[b][color=#ff0000]红色粗体[/color][/b]`。
- `[color=...]` 接受 `#rgb`、`#rrggbb`、`#rrggbbaa` 三种写法。
- `[size=N]` 要求正数，`[speed=N]` 要求正数，`[pause=N]` 要求大于等于 0。值不合法（包括空值和非数字）会在运行时报错。
- 闭标签必须和最近打开的标签同名；不匹配的闭标签会原样显示。
- 变量不存在时，`{$名字}` 输出空串。
- 不认识的标签、没闭合的 `[` 都会原样显示。
- 没有转义语法。想在正文里显示 `[` 或 `{$`，目前没有特殊写法。
- `[ruby]` 和 `[shake]` 不再是特殊标签，会连同内容一起原样显示。

## 12. 对话模式与语音

`@say` 可以显式写 `adv` 或 `nvl`；不写时默认 `adv`。`@choice` 不写 `mode=` 时同样默认 `adv`。

目前对话模式和 `voice=资源id` 都只记录在事件里，不会改变画面或播放语音，完整说明见 [limitations.md](limitations.md) 的「对话与语音」。

`speed=N` 会覆盖默认打字速度，单位是字/秒。

## 13. 保留值

下面这些词在特定位置有特殊含义。语法本身不禁止把它们当标签名或变量名，但建议避开，以免读起来混淆。

| 类别     | 取值                                                                    |
| -------- | ----------------------------------------------------------------------- |
| 位置名   | `farLeft`、`left`、`center`、`right`、`farRight`、`offLeft`、`offRight` |
| 转场名   | `fade`、`slide`、`slideL`、`slideR`、`zoom`、`none`                     |
| 缓动名   | `linear`、`ease`、`easeIn`、`easeOut`、`easeInOut`                      |
| 循环     | `loop`、`once`                                                          |
| 对话模式 | `adv`、`nvl`                                                            |
| 其他     | `all`（`@hide` 用）、`true`、`false`、`and`、`or`、`if`                 |

转场名或缓动名写错会作为参数错误报错；渲染层收到未知名字时仍分别按直切和 `linear` 回退。详见 [limitations.md](limitations.md)。

## 14. 常见错误

- 运算符两边没空格：`@set $x 1+2`，应写 `@set $x 1 + 2`。
- 把连字符当减号：`@set $x $hp-1` 会去找名为 `hp-1` 的变量，应写 `$hp - 1`。
- 选项块忘了 `@endchoice`，或者 `->` 后面没空格。
- 颜色等以 `#` 开头的值没加引号：`color=#fff` 解析失败，应写 `color="#fff"`。
- 时长忘了单位：`@wait 500`、`@shake 500` 会在运行时报错，应写 `500ms`。
- 多余或拼错的参数：未知键、类型不对、多余位置参数都会在运行时报错。
- `@say` 拼错键名、写多余位置参数，或者 `@if` / `@elseif` 漏写条件：解析阶段报错。
- 同一个键值参数写两次：解析阶段报错。
- 标签重复声明，或者元数据重复、排在指令之后：解析阶段报错，错误对象带 `phase` 与 `line`。
- 指令拼错：不认识的指令会在加载脚本时直接报错。
- 运行时错误：标签不存在、`@return` 没有对应 `@call`、`@if` 没闭合、富文本值非法、所有选项条件为假等。
