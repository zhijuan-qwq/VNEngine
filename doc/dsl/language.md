# 语言规则

这份文档讲所有指令共用的规则。只想知道某条指令怎么写的，查 [reference.md](reference.md)；第一次写剧本，从 [guide.md](guide.md) 开始。

## 1. 一行一条指令

正常情况下，一行写一条指令，执行顺序就是从上到下。

唯一的例外是选项块：`@choice` 和 `@endchoice` 之间要写多行选项，它本身就是一个多行结构。

空行会被忽略。缩进没有任何语法含义，只是让剧本更好读。整份脚本可以是空的，不会报错。

## 2. 注释

用 `//` 写单行注释。它有两种位置：

```vns
// 整行注释
@bg classroom  // 行尾注释
@set $x 1 // 赋值
```

不支持多行注释。

裸文本形式的元数据值会在 `//` 处截断，所以值本身含 `//` 时要用双引号：

```vns
@title 第一章 // 这不是标题的一部分
@title "A // B"
```

选项块内部允许空行和整行注释，方便把选项分组。

## 3. 名字

标签名、变量名、资源 ID、旗标名、位置名等都用同一种名字规则：

- 以字母或下划线开头；
- 后面可以是字母、数字、下划线、连字符；
- 区分大小写。

例如 `ch_hero`、`chapter2_start`、`auto_mode`、`farLeft` 都是合法的名字。

## 4. 字面量

| 类型   | 写法                    | 例子                         |
| ------ | ----------------------- | ---------------------------- |
| 字符串 | 双引号包围              | `"你好"`、`"第一行\n第二行"` |
| 数字   | 十进制，可带负号和小数  | `42`、`-7`、`3.14`、`-0.5`   |
| 布尔值 | `true` / `false`        | —                            |
| 时长   | 数字加 `ms` 或 `s` 单位 | `500ms`、`2s`、`1.5s`        |
| 普通词 | 不带引号的名字          | `classroom`、`center`        |
| 变量   | `$` 加名字              | `$affection`                 |
| 旗标   | `?` 加名字              | `?met_hero`                  |

几点说明：

- 字符串只支持双引号，转义只认 `\n`、`\t`、`\\`、`\"` 四种。
- 数字不写科学计数法，`1e3` 不是数字。
- **时长必须带单位**。`500ms` 和 `0.5s` 都行，只写 `500` 不行。
- 普通词会原样变成字符串。`@bg classroom` 里的 `classroom` 就是一个字符串。

## 5. 指令参数

指令后面可以跟两类参数：

- **位置参数**：按顺序读取，第一个位置、第二个位置……各表示什么由指令自己决定。
- **键值参数**：写成 `名字=值`，例如 `sprite=smile`、`volume=0.5`。

键值参数的右值可以带引号，引号里允许空格：

```vns
@sprite ch_hero smile
@say Hero "你好" speed=30
@bg classroom fade 1s
```

### 参数会按声明校验

每条指令只接受文档里列出的参数。下面这些情况都会报错，而不是悄悄忽略：

- 参数数量不对，或者多写了参数；
- 参数名不认识；
- 值的类型不对，例如该写数字的地方写了字符串；
- 同一个参数给了两次，或者两种写法互相冲突。

数字型键值要写不带引号的数字。`volume=0.5` 是数字，`volume="0.5"` 是字符串，后者会被当成类型错误。

## 6. 元数据

元数据只有三个键：

| 键         | 说明     |
| ---------- | -------- |
| `@title`   | 剧本标题 |
| `@author`  | 作者     |
| `@version` | 版本号   |

值可以直接写裸文本，也可以加双引号，两种等价：

```vns
@title 第一章 — 转校生
@author "Alice"
@version 1.0
```

裸文本会一直取到行尾或 `//` 之前，再去掉首尾空白。

元数据必须排在所有指令和标签之前，每个键只能出现一次。重复出现、顺序不对都会报错。元数据之前可以有注释和空行，只要还没出现真正的指令或标签。

键名必须完整匹配。`@titlefoo` 不会被当成 `@title`，它会被当作一条不认识的指令，在加载脚本时报错。

## 7. 脚本结构

一份脚本由下面这些行组成：

- 元数据行，例如 `@title ...`；
- 标签行，例如 `@label start`；
- 对话行：内联式 `Hero "你好"` 或 `@say Hero "你好"`；
- 普通指令行，例如 `@bg classroom`；
- 选项块 `@choice ... @endchoice`；
- 空行和注释行。

标签用 `@label 名字` 声明，是跳转和调用的落脚点。标签名不能重复，重复会在解析阶段报错。标签可以出现在使用它的 `@jump` / `@call` 之前或之后。

## 8. 流程

### 跳转、调用与返回

```vns
@label start
@jump chapter2_start

@call explore_scene
@return
```

- `@jump 标签` 无条件跳到标签处，不记录返回位置。
- `@call 标签` 调用一段子流程，并记下返回位置。
- `@return` 回到最近一次 `@call` 的下一条指令。

`@jump` 跳出当前 `@if` 块时会退出这个块，但不会退出最内层的 `@call`。`@return` 会把条件分支的状态截断回调用发生时的位置。这样跳转和返回就不会留下「半截」的分支状态。

标签不存在、或者 `@jump` / `@call` 忘了写标签名，会在运行时停到 `script:error`。

### 条件分支

```vns
@if 条件
  ...
@elseif 另一个条件
  ...
@else
  ...
@endif
```

`@if` 必须带条件；`@elseif` 可以有多个；`@else` 和 `@endif` 各最多一个。条件为真时，执行到下一个分支标记为止。

## 9. 选项块

```vns
@choice
  -> "回应她": respond
  -> "无视她": ignore
  -> "恶作剧": prank if $confidence >= 50
@endchoice
```

- 选项行以 `->` 开头，`->` 后面至少要有一个空格。
- 缩进可有可无，只影响好看。
- 冒号后面是选中后跳转的标签名。
- `if` 后面是可选的显示条件。
- 选项块里可以写空行和整行注释。
- 一个选项都没有的选项块会在解析阶段报错。

条件不成立的选项仍然显示，只是变灰、点不了。没写 `if` 的选项始终可点。玩家点中后，脚本跳到对应标签。

`@choice` 可以写 `mode=adv` 或 `mode=nvl`。这个值会记下来，但**目前不会改变画面**，见下面第 12 节。

## 10. 表达式

表达式可以用在三个地方：

- `@if` / `@elseif` 的条件；
- `@set`、`@add`、`@sub`、`@mul`、`@div`、`@mod`、`@random` 的右值；
- 选项行的 `if` 条件。

示例：

```vns
@set $total $base + $bonus
@add $hp $hp - 1
@random $dice 1 6
@if $affection >= 80 and ?met_hero
```

### 运算符与优先级

从高到低：

| 优先级 | 运算符                      |
| ------ | --------------------------- |
| 1      | `!` `-`（一元）             |
| 2      | `*` `/` `%`                 |
| 3      | `+` `-`（二元）             |
| 4      | `>` `>=` `<` `<=` `==` `!=` |
| 5      | `and`                       |
| 6      | `or`                        |

可以用括号改变顺序。比较运算不能连写，`1 < $x < 3` 不合法，要写成 `1 < $x and $x < 3`。

### 书写要求

- 二元运算符两侧必须有空格：`1 + 2` 合法，`1+2` 不合法。
- 一元运算符可以紧贴操作数，也可以连续写：`-$x`、`!!$flag` 都合法。

### 求值规则

- `and` / `or` 会短路：左边已经能决定结果时，右边不再计算。结果始终是布尔值 `true` / `false`。
- `==` / `!=` 同时比较类型和值，`1` 和 `"1"` 不相等。
- 大小比较和加减乘除按 JavaScript 的规则计算；`+` 也可以拼接字符串。
- 除以 0 不会报错，会得到 `Infinity`、`-Infinity` 或 `NaN`。
- 没定义的变量：在条件里当作假，在文本插值里输出空串，参与算术时得到 `NaN`。如果直接把它交给 `@add` / `@sub` 这类需要数字的指令，会报「不是数字」的错误。
- 真假的判断：`false`、`0`、`NaN`、空字符串、未定义都算假，其余算真。
- `?名字` 检查旗标是否存在。

## 11. 内联富文本

台词里可以加少量格式标签。标签只影响显示，不影响脚本逻辑。

| 标签                         | 作用             | 例子                            |
| ---------------------------- | ---------------- | ------------------------------- |
| `[b]...[/b]`                 | 加粗             | `"[b]重要[/b]"`                 |
| `[i]...[/i]`                 | 斜体             | `"[i]内心独白[/i]"`             |
| `[color=#rrggbb]...[/color]` | 文字颜色         | `"[color=#ff0000]红字[/color]"` |
| `[size=N]...[/size]`         | 字号             | `"[size=32]标题[/size]"`        |
| `[speed=N]`                  | 改变后续打字速度 | `"[speed=30]慢一点"`            |
| `[pause=N]`                  | 停顿 N 毫秒      | `"然后...[pause=1000]他走了。"` |
| `{$名字}`                    | 插入变量值       | `"好感度：{$affection}"`        |

`[speed=N]` 和 `[pause=N]` 是一次性标记，没有配对的结束标签。写成 `[/speed]` 不会被识别，会原样显示。

其余规则：

- 标签可以嵌套，例如 `[b][color=#ff0000]红色粗体[/color][/b]`。
- 颜色写 `#rrggbb`，格式不对会报错。字号、速度、停顿都写正数，写错同样会报错。
- 变量不存在时，`{$名字}` 输出空串。
- 不认识的标签、没闭合的 `[` 都会原样显示。
- 没有转义语法。想在正文里显示 `[` 或 `{$`，目前没有特殊写法。
- 早期的 `[ruby]` 和 `[shake]` 已经不再识别，写了会像普通文字一样显示出来。

## 12. 对话模式与语音

`@say` 和 `@choice` 都可以指定 `adv` 或 `nvl`，不写时默认 `adv`。

目前这两个模式**只记录在事件里，不会改变画面**：对话框始终是底部的样子。

对话指令里的 `voice=资源id` 同样只记录在事件里，**不会真的播放语音**。想播放声音，用 `@playVoice`。

`speed=N` 会覆盖默认打字速度，单位是字/秒。

## 13. 常见错误

- 时长忘了单位：`@wait 500`，应写 `@wait 500ms`。
- 运算符两边没空格：`@set $x 1+2`，应写 `@set $x 1 + 2`。
- 选项块忘了 `@endchoice`，或者 `->` 后面没空格。
- 指令拼错：不认识的指令会在加载脚本时直接报错。
- 多写了参数：大多数指令只接受固定数量的参数，多写的会报错。
