# 语言规则

这份文档讲所有指令共用的规则。只想知道某条指令怎么写的，查 [reference.md](reference.md)；第一次写剧本，从 [guide.md](guide.md) 开始；遇到与预期不符的行为，查 [limitations.md](limitations.md)。

## 1. 一行一条指令

正常情况下，一行写一条指令，执行顺序就是从上到下。

唯一的例外是选项块：`@choice` 和 `@endchoice` 之间要写多行选项，它本身就是一个多行结构。

空行会被忽略。缩进没有任何语法含义，只是让剧本更好读。整份脚本可以是空的，不会报错。

## 2. 注释

用 `//` 写单行注释。它有两种位置：

```vns
// 整行注释
@bg classroom // 行尾注释
@set $x 1 // 赋值
```

不支持多行注释。

裸文本形式的元数据值会在 `//` 处截断，所以值本身含 `//` 时要用双引号：

```vns
@title 第一章 // 这不是标题的一部分
```

```vns
@title "A // B"
```

选项块内部目前**不能写空行或整行注释**，否则会在解析阶段报错。行尾注释可以写：

```vns
@choice
  -> "回应她": respond // 这里可以写注释
@endchoice
```

详见 [limitations.md](limitations.md) 的「选项块」。

## 3. 名字

标签名、变量名，以及表达式里的旗标名（`?名字`）都用同一套 ASCII 名字规则：

- 只能使用 ASCII 字母、数字、下划线和连字符；
- 以字母或下划线开头，不能以数字或连字符开头；
- 中文不能直接当名字；
- 区分大小写。

例如 `ch_hero`、`chapter2_start`、`auto_mode`、`farLeft` 都是合法的名字。

资源 ID 和旗标指令（`@flag` / `@unflag` / `@toggle`）的参数是普通值，可以写成带引号的字符串，此时不受名字规则限制，空格和中文都行：`@bg "class room"`、`@flag "中文 旗标"`。只有不带引号时才必须符合上面的规则。

名字里允许连字符，这有一个容易踩的坑：`$hp-1` 是**一个名为 `hp-1` 的变量**，不是 `$hp` 减 1。减法必须写成 `$hp - 1`，运算符两边加空格。

## 4. 字面量

| 类型   | 写法                    | 例子                         |
| ------ | ----------------------- | ---------------------------- |
| 字符串 | 双引号包围              | `"你好"`、`"第一行\n第二行"` |
| 数字   | 十进制，可带负号和小数  | `42`、`-7`、`3.14`、`-0.5`   |
| 布尔值 | `true` / `false`        | —                            |
| 时长   | 数字加 `ms` 或 `s` 单位 | `500ms`、`2s`、`1.5s`        |
| 普通词 | 不带引号的名字          | `classroom`、`center`        |
| 变量   | `$` 加名字              | `$affection`                 |
| 旗标   | `?` 加名字              | `?met_hero`                  |

几点说明：

- 字符串只支持双引号，转义只认 `\n`、`\t`、`\\`、`\"` 四种。
- 数字不写科学计数法，`1e3` 不是数字。
- 时长可以写成 `500ms`、`1.5s`；指令也接受裸数字，并把裸数字当作**毫秒**。`@wait 500` 和 `@wait 500ms` 效果相同。推荐仍然写单位。
- 普通词会原样变成字符串。`@bg classroom` 里的 `classroom` 就是一个字符串。
- 普通词只能由名字允许的字符组成，所以 `#ffffff`、`#ff0000` 这类值必须加引号：`color="#ffffff"`。直接写 `color=#ffffff` 会解析失败。

## 5. 指令参数

指令后面可以跟两类参数：

- **位置参数**：不带名字的值，按出现顺序编号。
- **键值参数**：写成 `名字=值`，例如 `sprite=smile`、`volume=0.5`。

键值参数的右值可以带引号，引号里允许空格：

```vns
@say Hero "你好" speed=30
@bg classroom fade 1s
@bg "class room" fade 1s
@show ch_heroine right transition=fade duration=500ms
```

`"class room"` 是一个带空格的字符串值：引号会被去掉，空格保留。

### 位置参数怎么对应

**没有一套通用的「按顺序填空」规则。** 每条指令自己决定第几个位置参数是什么，而且读取方式并不统一。常见的几类：

| 指令              | 位置参数的读法                                                             |
| ----------------- | -------------------------------------------------------------------------- |
| `@bg`             | 第 1 个是资源 id；后面的时长当作时长，其他字符串当作转场名                 |
| `@show`           | 第 1 个是角色 id；第 2 个**永远当作位置**；再后面的字符串/时长是转场和时长 |
| `@hide`           | 第 1 个**永远当作角色 id**；后面的字符串/时长是转场和时长                  |
| `@move`           | 第 1 个是角色 id；第 2 个只有写成合法位置名时才当位置，否则留给时长/缓动   |
| `@sprite`         | 第 1 个是角色 id，第 2 个是立绘 id；后面是转场和时长                       |
| `@playBgm` 等音频 | 第 1 个是资源 id；只有第 2 个位置能写 `loop` / `once`，其他参数用键值      |
| `@set` 等变量指令 | 第 1 个是要写入的变量，后面是一个表达式                                    |
| `@random`         | 变量、下界、上界                                                           |

两个直接后果：

- `@show ch_hero slideL 500ms` 不会播放 `slideL` 转场：`slideL` 被当成位置，识别失败后回退 `center`。要写转场，先写位置（`@show ch_hero center slideL 500ms`），或用 `transition=slideL`。
- `@hide fade` 是「隐藏 id 为 `fade` 的角色」，不是「带淡出隐藏全部」。隐藏全部并带转场要写 `@hide all fade`。

### 参数不会被自动校验

每条指令只读取自己认识的参数，但**多余参数不一定被忽略**：

- 未知的键值参数（拼错键名、多写 `foo=1`）多半会被忽略，不会报错；但 `@say` 有专用语法，拼错键名或写多余的位置参数会让整行退回通用指令解析，运行时通常报错。
- `@choice` 拼错 `mode=` 会让后面的选项块失去归属，通常在解析阶段报错；不含任何选项的 `@choice`（无论是否写 `@endchoice`）都能通过解析，但执行时会报错。内联对话写多余参数则直接解析失败。
- 多余的位置参数可能被消费成别的槽位：`@bg` / `@show` / `@hide` 里多余的字符串会覆盖转场名，`@move` 里多余的字符串会覆盖缓动名。
- 同一个键写两次时，后写的覆盖先写的；
- 数字型键值写成字符串（例如 `volume="0.5"`）时，指令读不到数字，通常相当于没写。

值本身的类型确实不对、并且指令必须用到它时，才会在运行时报错，例如 `@add $hp "abc"` 会报 `Expected a number, got abc`。

## 6. 元数据

元数据只有三个键：

| 键         | 说明     |
| ---------- | -------- |
| `@title`   | 剧本标题 |
| `@author`  | 作者     |
| `@version` | 版本号   |

元数据必须排在所有指令和标签之前，每个键只能出现一次。重复出现、顺序不对都会在解析阶段报错。元数据之前可以有注释和空行，只要还没出现真正的指令或标签。

值的写法有两种，但**只在简单情况下等价**：

- 整段值是一个双引号字符串时，引号会被去掉：`@title "第一章"` 的值是 `第一章`；
- 否则整行到 `//` 之前都算裸文本，去掉首尾空白，**引号原样保留**：`@title 第一章` 的值是 `第一章`，`@title "第一章" 外传` 的值是 `"第一章" 外传`。

所以 `@title "A"` 和 `@title A` 等价；一旦引号和普通文字混写，就不再等价。

元数据键名目前不是完整匹配：`@titlefoo bar` 会被当成 `@title`，值是 `foo bar`。详见 [limitations.md](limitations.md)。

## 7. 脚本结构

一份脚本由下面这些行组成：

- 元数据行，例如 `@title ...`；
- 标签行，例如 `@label start`；
- 对话行：内联式 `Hero "你好"` 或 `@say Hero "你好"`；
- 普通指令行，例如 `@bg classroom`；
- 选项块 `@choice ... @endchoice`；
- 空行和注释行。

标签用 `@label 名字` 声明，是跳转和调用的落脚点。标签名不能重复，重复会在解析阶段报错。标签可以出现在使用它的 `@jump` / `@call` 之前或之后。

内联对话的说话者只能是不带引号的 ASCII 名字。要写 `"???"`、空名或中文说话者，改用 `@say`，并把说话者写成带引号的字符串：

```vns
Hero "你好。"
@say "???" "......"
@say "" "没有名字的台词。"
```

## 8. 流程

### 跳转、调用与返回

```vns
@label start
@jump chapter2_start

@call explore_scene
@return
```

- `@jump 标签` 无条件跳到标签处，不记录返回位置。
- `@call 标签` 调用一段子流程，并记下返回位置。
- `@return` 回到最近一次 `@call` 的下一条指令。

在 `@if` 块里 `@jump` 到块外是允许的，不需要先补 `@endif`。跳转不会影响 `@call` 的返回位置。

下面这些情况会在**运行时**报错，而不是加载时：

- 标签不存在，或者 `@jump` / `@call` 没写标签名；
- `@return` 时调用栈是空的（没有对应的 `@call`）。

### 条件分支

```text
@if 条件
  ...
@elseif 另一个条件
  ...
@else
  ...
@endif
```

`@if` 应带条件；`@elseif` 可以有多个；`@else` 和 `@endif` 各写一个。条件为真时，执行到下一个分支标记为止。

漏写条件不会报错：这一行会退回通用指令解析，运行时把缺失的条件当作「假」，于是走 `@elseif` / `@else` 分支，没有其他分支就跳过整块。`@elseif` 漏写条件同理。所以「条件必填」是语法之外的要求，引擎不会替你拦住。

分支结构是嵌套的，`@if` 里可以再写 `@if`。结构错误在运行到相关行时才暴露：

- `@if` 没有配对的 `@endif`：执行到 `@if` 时报 `Unclosed @if block`；
- 多余的 `@endif`、`@elseif`、`@else`：执行到该行时报错；
- `@else` 写在 `@elseif` 之前**不会报错**：第一个成立的分支先执行，后面的全部跳过。

## 9. 选项块

```vns
@choice
  -> "回应她": respond
  -> "无视她": ignore
  -> "恶作剧": prank if $confidence >= 50
@endchoice
```

- 选项行以 `->` 开头，`->` 后面至少要有一个空格。
- 缩进可有可无，只影响好看。
- 冒号后面是选中后跳转的标签名。
- `if` 后面是可选的显示条件。
- 行尾可以写 `//` 注释。
- 选项块内部目前不能写空行或整行注释。

条件不成立的选项仍然显示，只是变灰、点不了。没写 `if` 的选项始终可点。玩家点中后，脚本跳到对应标签。

一个选项都没有的 `@choice` 能通过解析，但执行到它时会报错。所有选项的条件都为假时，玩家会卡在选择界面，详见 [limitations.md](limitations.md)。

`@choice` 可以写 `mode=adv` 或 `mode=nvl`，不写时默认 `adv`。这个值会记录在事件里，但**目前不会改变画面**。

## 10. 表达式

表达式可以用在三个地方：

- `@if` / `@elseif` 的条件；
- `@set`、`@add`、`@sub`、`@mul`、`@div`、`@mod`、`@random` 的右值；
- 选项行的 `if` 条件。

示例：

```vns
@set $total $base + $bonus
@sub $hp 1
@set $hp $hp - 1
@random $dice 1 6
@if $affection >= 80 and ?met_hero
```

注意 `@sub $hp 1` 是在原值上减 1；`@add $hp $hp - 1` 会变成「原值加上原值减一」，通常不是想要的结果。

### 运算符与优先级

从高到低：

| 优先级 | 运算符                      |
| ------ | --------------------------- |
| 1      | `!` `-`（一元）             |
| 2      | `*` `/` `%`                 |
| 3      | `+` `-`（二元）             |
| 4      | `>` `>=` `<` `<=` `==` `!=` |
| 5      | `and`                       |
| 6      | `or`                        |

可以用括号改变顺序。比较运算不能连写，`1 < $x < 3` 不合法，要写成 `1 < $x and $x < 3`。

### 书写要求

- 二元运算符两侧必须有空格：`1 + 2` 合法，`1+2` 不合法。
- 一元运算符可以紧贴操作数，也可以连续写：`-$x`、`!!$flag` 都合法。

### 求值规则

- `and` / `or` **不会短路**：左右两边都会先算出来，再合并。它们返回的是操作数本身，不是固定布尔值：`0 or 5` 得到 `5`，`1 and 2` 得到 `2`。
- `==` / `!=` 同时比较类型和值，`1` 和 `"1"` 不相等。
- 大小比较和加减乘除按 JavaScript 的规则计算；`+` 也可以拼接字符串。
- 真假的判断：`false`、`0`、`NaN`、空字符串、未定义都算假，其余算真。
- 除以 0 不会报错，会得到 `Infinity`、`-Infinity` 或 `NaN`。这些值存档后会变成 `null`。
- 没定义的变量：在条件里当作假，在文本插值里输出空串，参与算术时得到 `NaN`。如果直接把它交给 `@add` / `@sub` 这类需要数字的指令，会报 `Expected a number, got undefined`。
- 右侧引用一个不存在的变量时，`@set $x $missing_var`（变量名只能是 ASCII）会把 `x` 设为未定义值；之后存档时这个键会消失。
- `?名字` 检查旗标是否存在。

## 11. 内联富文本

台词里可以加少量格式标签。标签只影响显示，不影响脚本逻辑。

| 标签                         | 作用             | 例子                            |
| ---------------------------- | ---------------- | ------------------------------- |
| `[b]...[/b]`                 | 加粗             | `"[b]重要[/b]"`                 |
| `[i]...[/i]`                 | 斜体             | `"[i]内心独白[/i]"`             |
| `[color=#rrggbb]...[/color]` | 文字颜色         | `"[color=#ff0000]红字[/color]"` |
| `[size=N]...[/size]`         | 字号             | `"[size=32]标题[/size]"`        |
| `[speed=N]`                  | 改变后续打字速度 | `"[speed=30]慢一点"`            |
| `[pause=N]`                  | 停顿 N 毫秒      | `"然后...[pause=1000]他走了。"` |
| `{$名字}`                    | 插入变量值       | `"好感度：{$affection}"`        |

目前**只有 `[speed=N]`、`[pause=N]` 和 `{$名字}` 会实际影响显示**：速度和停顿生效，变量会被替换。`[b]`、`[i]`、`[size=N]` 会被解析，其中字号和粗斜体会参与排版测量；`[color=...]` 只是被记录，既不参与测量也不影响渲染。这些标签都**不会改变实际文字外观**，详见 [limitations.md](limitations.md)。

`[speed=N]` 和 `[pause=N]` 是一次性标记，没有配对的结束标签。写成 `[/speed]` 不会被识别，会原样显示。

其余规则：

- 标签可以嵌套，例如 `[b][color=#ff0000]红色粗体[/color][/b]`。
- `[size=N]` 要求正数，`[speed=N]` 要求正数，`[pause=N]` 要求大于等于 0。值不合法时不会报错，开标签直接被丢弃；配对的闭标签可能关掉外层样式，或者在没有外层样式时原样显示在正文里。
- 变量不存在时，`{$名字}` 输出空串。
- 不认识的标签、没闭合的 `[` 都会原样显示。
- 没有转义语法。想在正文里显示 `[` 或 `{$`，目前没有特殊写法。
- `[ruby]` 和 `[shake]` 仍会被识别，但没有任何视觉效果，里面的文字照常显示。

## 12. 对话模式与语音

`@say` 可以显式写 `adv` 或 `nvl`；不写时事件里的 `mode` 是 `undefined`。`@choice` 不写 `mode=` 时默认 `adv`。

目前对话模式和 `voice=资源id` 都只记录在事件里，不会改变画面或播放语音，完整说明见 [limitations.md](limitations.md) 的「对话与语音」。

`speed=N` 会覆盖默认打字速度，单位是字/秒。

## 13. 保留值

下面这些词在特定位置有特殊含义。语法本身不禁止把它们当标签名或变量名，但建议避开，以免读起来混淆。

| 类别     | 取值                                                                    |
| -------- | ----------------------------------------------------------------------- |
| 位置名   | `farLeft`、`left`、`center`、`right`、`farRight`、`offLeft`、`offRight` |
| 转场名   | `fade`、`slide`、`slideL`、`slideR`、`zoom`、`none`                     |
| 缓动名   | `linear`、`ease`、`easeIn`、`easeOut`、`easeInOut`                      |
| 循环     | `loop`、`once`                                                          |
| 对话模式 | `adv`、`nvl`                                                            |
| 其他     | `all`（`@hide` 用）、`true`、`false`、`and`、`or`、`if`                 |

转场名写错不会报错，会按直切处理；缓动名写错也不会报错，会回退 `linear`。详见 [limitations.md](limitations.md)。

## 14. 常见错误

- 运算符两边没空格：`@set $x 1+2`，应写 `@set $x 1 + 2`。
- 把连字符当减号：`@set $x $hp-1` 会去找名为 `hp-1` 的变量，应写 `$hp - 1`。
- 选项块里写了空行或整行注释：会解析失败，注释请写在行尾。
- 选项块忘了 `@endchoice`，或者 `->` 后面没空格。
- 颜色等以 `#` 开头的值没加引号：`color=#fff` 解析失败，应写 `color="#fff"`。
- 内联对话用了引号或中文说话者：`"???" "……"`、`旁白 "……"` 都不是合法内联写法，改用 `@say`。
- `@say 小明 "……"` 会解析失败：`@say` 的说话者要加引号，写成 `@say "小明" "……"`。
- `@if` / `@elseif` 漏写条件不会报错，而是被当作「假」，整块可能被静默跳过，务必检查条件是否写全。
- 标签重复声明，或者元数据重复、排在指令之后：解析阶段报错。
- 指令拼错：不认识的指令会在加载脚本时直接报错。
- 运行时错误：标签不存在、`@return` 没有对应 `@call`、`@if` 没闭合、所有选项条件为假等。
