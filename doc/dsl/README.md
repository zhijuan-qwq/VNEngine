# VNScript 文档

VNScript 是 VNEngine 的剧本语言，源文件扩展名是 `.vns`。一份剧本就是按顺序执行的一串指令：切换背景、让角色说话、给出选项、按条件走不同分支。

## 按需要选文档

| 文档                         | 适合谁                 | 讲什么                                                       |
| ---------------------------- | ---------------------- | ------------------------------------------------------------ |
| [guide.md](guide.md)         | 第一次写剧本的人       | 从一个完整的小剧本入手，学会最常用的指令                     |
| [reference.md](reference.md) | 已经会写、要查细节的人 | 每条指令的写法、参数、示例和对应事件                         |
| [language.md](language.md)   | 所有剧本作者           | 所有指令共用的规则：注释、字面量、参数、表达式、流程、富文本 |
| [internals.md](internals.md) | 引擎和插件开发者       | 解析后的数据结构、执行流程、自定义指令、事件                 |
| [conflicts.md](conflicts.md) | 维护者                 | 文档与旧实现之间的差异清单，以及逐条确认后的处理方向         |

建议的阅读顺序：先读 guide，遇到不确定的写法查 reference，想弄清「为什么能这么写」时看 language；要改引擎或加指令再看 internals。

## 语法从哪里来

真正决定一份脚本能不能解析的，只有 `src/script/grammar.pegjs`。本目录的文档用更容易读的方式描述它，不另外维护一套形式化语法。文档与解析器不一致时，以解析器为准。

## 关于实现进度

本目录描述的是已经确认的目标行为。其中一部分还需要代码跟进，例如命令参数按声明校验、`@wait` 必须带时长、`and` / `or` 短路并返回布尔值、富文本非法值报错等。每条的状态都记在 [conflicts.md](conflicts.md) 的「已定方向」里，修改代码时按那份清单逐条勾掉即可。

已经明确暂时不生效的两点，在 reference 里照实写了：对话模式 `adv` / `nvl` 目前只记录、不改变画面；`voice=` 目前只记录、不会播放。
