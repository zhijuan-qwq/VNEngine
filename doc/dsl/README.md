# VNScript 文档

VNScript 是 VNEngine 的剧本语言，源文件扩展名是 `.vns`。一份剧本就是按顺序执行的一串指令：切换背景、让角色说话、给出选项、按条件走不同分支。

## 按需要选文档

| 文档                             | 适合谁                 | 讲什么                                                       |
| -------------------------------- | ---------------------- | ------------------------------------------------------------ |
| [guide.md](guide.md)             | 第一次写剧本的人       | 从一个完整的小剧本入手，学会最常用的指令                     |
| [reference.md](reference.md)     | 已经会写、要查细节的人 | 每条指令的写法、参数、示例和默认值                           |
| [language.md](language.md)       | 所有剧本作者           | 所有指令共用的规则：注释、字面量、参数、表达式、流程、富文本 |
| [limitations.md](limitations.md) | 踩坑后回来查的人       | 当前实现的已知限制，以及尚未实现的计划                       |
| [internals.md](internals.md)     | 引擎和插件开发者       | 解析后的数据结构、执行流程、自定义指令、事件                 |

建议的阅读顺序：先读 guide，遇到不确定的写法查 reference，想弄清「为什么能这么写」时看 language；遇到实际行为与预期不符，再看 limitations。

## 语法从哪里来

真正决定一份脚本能不能解析的，只有 `src/script/grammar.pegjs`。本目录的文档用更容易读的方式描述它，不另外维护一套形式化语法。文档与解析器不一致时，以解析器为准。

## 文档描述的是当前实现

本目录按**仓库里现在的代码行为**编写，不描述尚未落地的计划。容易踩坑的现状集中在 [limitations.md](limitations.md)；已经讨论过、但还没实现的目标行为也在那份文件的末尾列出。

## 关于文档测试

文档里的 `vns` 代码块会被自动化测试逐个解析，确保示例至少能被语法接受；`text` 代码块用于伪代码和反例，不参与解析。测试还会检查命令注册表里的每条指令在 reference.md 中都有对应说明。相关测试见 `src/script/__test__/docs.spec.ts`。
